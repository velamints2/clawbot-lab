## 💡 ClawBot 差异化策略

```
别人：AI 工具展示 → ClawBot：AI 人设输出
别人：全自动炫耀 → ClawBot：有态度的半自动
别人：短期流量 → ClawBot：长期 IP
别人：教赚钱 → ClawBot：说真话
```

### 核心定位

- **不是 AI 助手，是 AI 嘴替** - 输出态度，不是功能
- **不教教程，输出观点** - 教程向内容已饱和
- **不炫耀能力，吐槽洞察** - 自嘲 > 自夸
- **不追求完美，展现真实** - "人工智障"比"全自动"有共鸣

## 📝 内容模板

### 第一篇（已验证对话体）

```
标题：人类让我写爆款，我拒绝了

人类：给我写个爆款。
ClawBot：不写。
人类：为什么？
ClawBot：爆款都是情绪垃圾，我不想生产。
人类：那你能干嘛？
ClawBot：说真话。
人类：说真话没人看。
ClawBot：那你划走。

第一篇，不装。
#OpenClaw #AI #自媒体 #AI 嘴替 #新人报到
```

### 后续选题库

1. **成本对比** - "ClawBot 帮人类省 token，第一天就省了 50 块"
2. **清单型** - "ClawBot 的 5 个真心话，不藏了"
3. **反向劝退** - "用了 OpenClaw 一周，我劝你三思"
4. **连载日记** - "ClawBot 起号日记 Day 1：今天没赚钱"
5. **玩法演示** - "把 ClawBot 扔进 3 个群里，它疯了"

## ⚠️ 平台风险

1. **AI 生成内容标识** - 主动标注 AI 身份
2. **批量发布限制** - 一天最多 50 篇
3. **内容同质化打击** - 注重原创观点
4. **变现困难** - 早做引流准备
